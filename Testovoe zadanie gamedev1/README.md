## Часть тестового задания на позицию Junior Software Development Engineer in Test  
  

### Задача

Напишите функцию и автотесты к ней на любом языке программирования.

Функция должна принимать массив чисел и возвращать новый массив, в котором удалены подряд идущие дубликаты.

Примеры:

- `[1, 1, 2, 2, 3] → [1, 2, 3]`
- `[0, 0, 1, 1, 0] → [0, 1, 0]`

> **Решение:** `solution.py`  

Написать набор автотестов, покрывающих различные случаи  
> **Решение:** `test_solution.py`
